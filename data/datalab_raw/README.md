# 데이터랩 다운로드 원본을 넣는 곳

한국관광 데이터랩(datalab.visitkorea.or.kr)은 **무단 수집을 금지**합니다. 크롤러를
쓰지 말고, 사이트에서 직접 내려받은 폴더를 **압축만 풀어** 여기에 통째로 두세요.

```
data/datalab_raw/
├── 20260924212535_경주시_2023-2025_데이터랩_다운로드/
│   ├── 20260924212535_관광소비_내국인.csv
│   └── ...
└── 20260924212727_경주시_2023-2025_데이터랩_다운로드/
    └── ...
```

폴더 이름은 바꾸지 마세요. `src/datalab.py`가 **폴더명에서 지역을 읽습니다**
(`20260924212535_`**`경주시`**`_2023-2025_...`). CSV 안에는 지역·기간 정보가
없어서 폴더명이 유일한 단서입니다.

## 받는 방법

```
데이터랩 > 지역별 분석 > 지역별 현황 > 지역별 관광 현황
→ 지역 선택 → 기준/기간 선택 → 조회
→ 탭([관광소비], [인기관광지] …)으로 이동해 각 탭의 "데이터 다운로드"
```

로그인이 필요합니다. 상단 "전체 다운로드"는 **현재 탭의 것만** 받아지므로,
탭을 옮겨 가며 받아야 합니다.

## 이 폴더는 커밋하지 않습니다

원본 재배포는 제공처 이용 조건에 걸릴 수 있어 `.gitignore`로 제외했습니다.
계산 결과(`data/derived/datalab.json`)만 커밋합니다.
