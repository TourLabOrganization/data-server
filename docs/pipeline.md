# 파이프라인

## 구조

```
pipeline/
├── common.py    경로·한글 정규화·지역명 변환·CSV 읽기   ← 공용
├── places.py    앱 .dc.html      → places.json
├── datalab.py   데이터랩 CSV     → datalab.json
└── verify.py    두 쪽을 맞대어 검증 (산출물 없음, 콘솔 출력)
```

공용 로직은 반드시 `common.py` 에 둔다. 지역명 변환처럼 규칙이 미묘한 것을
각 스크립트가 따로 들고 있으면, 한쪽만 고쳤을 때 결과가 조용히 어긋난다.
실제로 그런 일이 있어서 모았다.

## 실행

```bash
make all                      # 전체
python -m pipeline.datalab    # 개별. 패키지로 돌려야 common.py 를 찾는다
```

`python pipeline/datalab.py` 처럼 직접 경로로 돌리면 상대 import가 깨진다.

## 각 단계가 하는 일

### places.py — 앱 HTML에서 장소 꺼내기

앱은 장소 1,171곳을 정적 HTML 한 파일(24,000줄) 안에 JS 객체 리터럴로 들고
있다. JSON이 아니라서 파서를 쓸 수 없고, 앱을 실행하지 않고 읽어야 하므로
정규식으로 파싱한다.

깨지기 쉬운 방식이라, 추출 결과가 `MIN_EXPECTED`(1,000) 미만이면 **실패시킨다.**
앱 포맷이 바뀌었을 때 조용히 일부만 빠지는 것이 가장 위험하기 때문이다.

블록 탐색은 반드시 `const DATA` 뒤에서만 한다. `seoul:` `jeju:` 같은 키가
`ORIGINS`·`REGION_HUB` 같은 다른 상수에도 있어서, 앞에서 걸리면 엉뚱한 블록을
읽는다.

### datalab.py — 지역×테마 강도(TFI)

두 종류의 데이터랩 탭을 쓴다.

| 탭 | 뽑는 것 | 테마 |
|---|---|---|
| 관광소비_내국인 | 업종대분류 비율(%) | 미식·쇼핑 |
| 인기관광지_전체 | 분류 구성비 | 역사·문화유산·자연·힐링 |

정규화는 로그 입지계수(LQ) 방식이다. 받은 지역들의 평균을 기준으로 각 지역이
얼마나 그 테마에 치우쳐 있는지를 재고, 0~1로 편다.

**지역이 2곳 미만이면 계산하지 않고 `null` 을 넣는다.** 비교 기준이 없는데
숫자를 만들면 거짓이 된다.

### verify.py — 앱과 데이터랩이 맞물리는지

지표 3개를 찍는다.

1. **앱 대상 매칭률** — 데이터랩 인기관광지 중 앱에도 있는 비율
2. **순위상관** — 앱 추천 순서 ↔ 데이터랩 인기 순위 (스피어만)
3. **TOP5 포함** — 데이터랩 상위 5곳 중 앱 추천 상위 5곳에 든 수

모수를 3단으로 나눈다. 데이터랩 '인기관광지'는 통신·카드 기반 **방문지**라
공항·호텔·백화점이 섞여 있어서, 전체를 분모로 쓰면 앱이 애초에 다루지 않는
대상까지 "놓친 것"으로 잡힌다.

```
데이터랩 TOP100
├─ 숙박·교통     제외 (NOT_TOURISM)
├─ 쇼핑시설      제외 (OUT_OF_SCOPE) — 앱에 쇼핑 카테고리가 없다
└─ 앱 대상       ← 이게 분모
```

전통시장은 앱이 `food` 로 다루므로 제외하지 않는다.

순위상관은 **양쪽에 다 있는 장소로만** 잰다. 한때 미매칭 장소에 더미 순위를
채워 넣었는데, 그 더미가 상관계수를 지배해서 실제와 반대 부호가 나왔다.
표본이 `MIN_PAIRS`(5) 미만이면 수치를 내지 않고 "측정 불가"로 찍는다.

## 새 지역 추가하기

1. 데이터랩에서 CSV를 받아 `data/datalab_raw/<다운로드폴더>/` 에 통째로 둔다.
   폴더명(`20260925200050_제주특별자치도_...`)에서 지역을 읽으므로 이름을 바꾸지 않는다
2. 지역명이 앱 표기와 다르면 `data/mapping/regions.csv` 에 한 줄 추가한다
3. `make all`
4. `verify` 의 매칭률이 떨어졌으면 이름 표기 차이일 가능성이 높다.
   `common.py` 의 `REGION_PREFIX`·`NAME_TAIL` 을 본다

지역을 추가하면 **기존 지역의 TFI 값도 바뀐다.** 평균이 기준이기 때문이며,
정상 동작이다 (`docs/contract.md`).

## 새 스크립트를 추가할 때

- 경로·정규화는 `common.py` 에서 가져온다. 새로 만들지 않는다
- 산출물은 `data/derived/` 에 쓰고 `docs/contract.md` 에 스키마를 적는다
- 외부 API를 부르면 응답을 `data/cache/` 에 캐싱해서 중간에 끊겨도
  이어받게 한다. 캐시는 커밋하지 않는다
- 키가 없으면 그 단계만 건너뛰고 나머지는 돌게 한다
